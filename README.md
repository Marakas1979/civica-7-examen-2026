# Cívica 7.º · Guía web de estudio

Guía interactiva para el examen del I Taller de Cívica, III trimestre 2026. Resume los contenidos del temario y del libro, páginas 122–135, y agrega una práctica de selección única y un simulacro escrito con clave.

## Publicación local

Abrí `index.html` en un navegador. El sitio no requiere dependencias ni servicios de servidor.

El avance de la práctica se guarda en `localStorage` de ese navegador. No recopila ni envía respuestas.

## Publicación en GitHub Pages

La página está preparada para publicarse desde la rama `main`, carpeta raíz (`/`).
