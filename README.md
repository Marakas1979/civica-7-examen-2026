# Cívica 7.º · Guía web de estudio

Guías interactivas para estudiar Cívica de sétimo año. La página principal resume el I Taller de Cívica, III trimestre 2026, sobre gestión del riesgo. La carpeta `ultimo-examen-transito/` reúne el Taller 5 (páginas 138–141), sobre comités y gestión de emergencias, y los talleres 6 y 7 (páginas 90–97), sobre la Ley de Tránsito. El Taller 8 permanece fuera de esta guía de examen.

## Publicación local

Abrí `index.html` en un navegador. El sitio no requiere dependencias ni servicios de servidor.

Para abrir el repaso del último examen localmente, abrí `ultimo-examen-transito/index.html`.

El avance de la práctica se guarda en `localStorage` de ese navegador. No recopila ni envía respuestas.

## Publicación en GitHub Pages

La página está preparada para publicarse desde la rama `main`, carpeta raíz (`/`). El repaso nuevo estará disponible en `/ultimo-examen-transito/`.
